# GerenciadorDeEstoque

Aplicativo mobile desenvolvido com React Native e Expo para controle de estoque doméstico de alimentos.

## Funcionalidades incluídas no código

- Tela de login e cadastro demonstrativos.
- Cadastro, edição e consulta de alimentos.
- Controle de quantidade, unidade, categoria e validade.
- Leitura de QR Code pela câmera usando `expo-camera`.
- Telas de estoque, alertas, receitas e perfil (conforme implementadas no protótipo).

## Requisitos

- Node.js instalado.
- npm.
- Expo Go no celular para testar recursos compatíveis.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no terminal.
3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o Expo:

   ```bash
   npx expo start
   ```

5. Leia o QR Code exibido no terminal com o Expo Go.

Para instalar/ajustar versões compatíveis de pacotes Expo, use:

```bash
npx expo install --fix
```

## Observações importantes

- O login e o cadastro presentes nesta versão são demonstrativos. Os dados de usuário ficam apenas em memória e não constituem autenticação real.
- Os dados do estoque também não estão conectados a um banco de dados nesta versão.
- Antes de usar em produção, conecte um serviço de autenticação e banco de dados, configure regras de segurança e não envie senhas, tokens ou chaves privadas ao GitHub.
- O acesso à câmera requer permissão do usuário e deve ser testado em um aparelho físico.
